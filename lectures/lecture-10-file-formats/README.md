# ლაბ 10 ფაილებთან მუშაობა

ყველა ბრძანება გაუშვი პროექტის ძირიდან, გააქტიურებული .venv გარემოთი.

## თეორია

CSV არის ცხრილი; DictReader მნიშვნელობებს ტექსტად კითხულობს. JSON ინარჩუნებს რიცხვებს, ლოგიკურ მნიშვნელობებსა და ჩადგმულ სტრუქტურას. XML იყენებს ტეგებს; ჩვენი მარტივი წამკითხველი მუშაობს სტრუქტურაზე root → ჩანაწერები → ტექსტური ველები და არ ახდენს ატრიბუტების ან რთული ჩადგმული სტრუქტურის ნორმალიზაციას.

UTF-8 BOM-ისთვის ვიყენებთ utf-8-sig-ს. FileImportError აერთიანებს იმპორტის შეცდომებს. წაკითხვადი ფაილი ყოველთვის სწორ მონაცემებს არ ნიშნავს: CSV-ში ვამოწმებთ საჭირო სვეტებს, XSD-ში კი XML-ის სტრუქტურასა და ტემპერატურის რიცხვით ტიპს.

pandas-ის DataFrame ცხრილური ობიექტია. groupby ვალუტის მიხედვით აჯგუფებს ჩანაწერებს; agg ითვლის საშუალოს, მინიმუმსა და მაქსიმუმს. Excel იკითხება და იწერება openpyxl ძრავით, index=False ზედმეტი ინდექსის სვეტს გამორიცხავს.

read_file გაფართოების მიხედვით ირჩევს წამკითხველს. მხარდაჭერილია CSV, JSON, GeoJSON, XML და XLSX. უცნობი ან არმქონე გაფართოება იწვევს შეცდომას. გაფართოება შიგთავსის სანდო მტკიცებულება არ არის: ფაილს შეიძლება არასწორი სახელი ჰქონდეს. Excel აბრუნებს DataFrame-ს; CSV/XML სიას, JSON კი შესაბამის Python ობიექტს. ერთიანი სქემის ნორმალიზაცია დამატებითი ეტაპია.

SeismicClient იყენებს ლაბ 9-ის შერჩევით retry-ს. GeoJSON კოორდინატების რიგია longitude, latitude, depth; დრო მილიწამებიდან UTC datetime-ში გადადის.
